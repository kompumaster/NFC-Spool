# Архитектура

## Слои

```text
lib/
  core/
    nfc/          NFC-транспорт и состояние доступности
    utils/        hex, BCC, атомарная запись файлов
  data/
    qidi/         модели, списки, CFG, .bin
    openspool/    модели, NDEF, NTAG layout, .bin
    records/      сохранённые метки и JSON-хранилище
    snapmaker/    настройки и модели U1
  services/
    qidi_tag_service.dart
    openspool_tag_service.dart
    snapmaker_service.dart
    snapmaker_status_service.dart
  ui/             экраны и виджеты
  l10n/           русско-английские строки
```

## NFC

- `NfcTagTransport` - абстракция сессии.
- `FlutterNfcTagTransport` - Android NFC через `flutter_nfc_kit`.
- `NfcService`:
  - проверка доступности;
  - состояние `NfcStatus`;
  - глобальная блокировка `runExclusive`;
  - `isBusy`.
- QIDI и OpenSpool создают свой транспорт на операцию.
- Все операции чтения и записи проходят через `runExclusive`.

## QIDI

- MIFARE Classic 1K.
- Сектор 1, блок 4.
- Ключ A `FFFFFFFFFFFF`.
- Чтение и запись с проверкой после записи.
- UID читается из Android NFC tag.

## OpenSpool

- NTAG215/216.
- Определение layout по CC.
- Raw-команды:
  - `0x60` - GET_VERSION;
  - `0x30` - чтение страниц;
  - `0xA2` - запись страницы.
- NDEF MIME: `application/json`.
- `OpenSpoolTagData.detectedProfile` определяет Standard/U1 по JSON.
- При чтении профиль и tier переключаются автоматически.
- При импорте `.bin` профиль берётся из дампа.

## Хранение

- `records.json` в документах приложения.
- Атомарная запись через `.tmp` и `rename`.
- Восстановление из `.bak` при потере основного файла.
- Настройки, QIDI CFG и Snapmaker host/port - в `SharedPreferences`.
- ToolHead не сохраняется, а запрашивается по HTTP.

## Snapmaker

- `SnapmakerService` выполняет HTTP-запросы.
- `SnapmakerStatusService` хранит общий статус:
  - `unknown`;
  - `checking`;
  - `available`;
  - `unavailable`.
- Кнопки U1 блокируются, пока статус не `available`.
- Ошибки классифицируются и не показывают тело HTTP-ответа.
- HTTP-клиент закрывается после каждого использования.
