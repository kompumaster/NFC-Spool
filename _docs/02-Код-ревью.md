# Код-ревью

## Уже исправлено

- Глобальная блокировка одновременных NFC-операций.
- Определение профиля OpenSpool/U1 при чтении и импорте `.bin`.
- Разделение состояний NFC: checking, available, disabled, unsupported, error.
- Атомарная запись `records.json`.
- Закрытие HTTP-клиента Snapmaker.
- Локализация оставшихся строк.
- Версия из `package_info_plus`.
- Обработка ошибок Snapmaker без огромного тела ответа.
- Блокировка кнопок U1 при неизвестном или недоступном Snapmaker.
- Сброс результата перед новым чтением метки.
- Adaptive icon для Android 8+.
- Стабильный прогон тестов по файлам и CI для Ubuntu и Windows.

- `logo_src/gen02.psd` может быть новее экспортированного `logo/gen02.png`.
- Локальный ключ подписи нужно хранить отдельно от Git и сделать резервную копию.
