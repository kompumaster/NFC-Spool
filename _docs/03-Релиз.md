## F-Droid

- Рецепт: `fdroid/io.github.kompumaster.nfcspool.yml`.
- Fastlane: `fastlane/metadata/android/en-US` и `fastlane/metadata/android/ru-RU`.
- Перед подачей добавить скриншоты в `images/phoneScreenshots/`.
- F-Droid собирает из исходников и подписывает APK своим ключом; переход с GitHub APK требует удаления и переустановки.
- Репозиторий создан 25.10.2026, поэтому действует правило активной разработки не менее 3 месяцев.

## Тесты

```powershell
flutter analyze
_tools\run_tests.bat
```

`run_tests.bat` запускает файлы по одному: `flutter_tester.exe` на Windows иногда падает с `0xc0000005`, и повторяется только сбой загрузки движка. CI использует тот же скрипт на Ubuntu и Windows.

## Сборка

```powershell
flutter pub get
flutter analyze
_tools\run_tests.bat
flutter build apk --release
flutter build apk --release --split-per-abi
```

Чистый клон собирается без `android/gradlew*`: Flutter сам восстанавливает Gradle wrapper. Без `android/key.properties` release APK получит debug-подпись.

Готовые APK лежат локально в `release/`; эта папка игнорируется Git.
